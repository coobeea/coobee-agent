# emit_event 后端→前端事件链路缺失 - 需求分析

> 创建时间：2026-04-29

## 需求背景

`emit_event` 工具（`src/main/agent/tools/builtin/emit-event.ts`）的设计意图是让 Agent 在运行过程中向前端发送 UI 事件，支持三种预定义类型：

- `open-preview` — Agent 启动 dev server 后通知前端打开网页预览
- `open-file` — Agent 生成文件后通知前端打开查看
- `notify` — 向用户显示通知消息

工具的 JSDoc 声明：**「事件通过 Gateway WebSocket 广播给所有连接的前端客户端」**

## 核心问题：事件链路在 EventBus 处断裂

当前 `emit_event` 工具只完成了发射：

```
emit_event 工具
  │
  └─► eventBus.emit('agent:event', payload)     ← 发射到 EventBus
        │
        └─► ❌ 无人监听，事件丢失
```

### 缺失环节一：后端没有 EventBridge 转发到 Gateway

现有的 Gateway Publisher 只有两个：

| Publisher | 转发的事件 |
|-----------|-----------|
| `StreamPublisher.ts` | `stream:message`、`stream:start`、`stream:end`、`stream:error` |
| `ThreadPublisher.ts` | `thread:message` |

**没有 AgentEventPublisher** 监听 `agent:event` 并调用 `gateway.broadcastEvent()` 推送到前端。

代码证据：搜索 `agent:event` 在 `src/` 下的监听者，只在测试文件中出现：
- `src/main/agent/tools/__tests__/emit-event.test.ts:36` — 测试 spy
- 生产代码中零处监听

### 缺失环节二：前端没有监听 agent 事件

搜索 `src/renderer/` 和 `src/shared/events/`，没有任何地方处理 agent 事件。三种预定义事件（`open-preview`、`open-file`、`notify`）在前端均无对应 handler。

### 缺失环节三：`agent:event` 游离于事件类型体系之外

`src/shared/events/` 中定义了完整的事件类型体系：

- `internal.ts` — 内部事件（app、window、lifecycle、db、workspace 等）
- `ipc.ts` — IPC 事件（前后端通信）
- `gateway.ts` — Gateway 事件（`stream:message`、`thread:message`）
- `frontend.ts` — 前端事件聚合类型

`agent:event` 不在上述任何类型体系中，直接使用字符串字面量 `eventBus.emit('agent:event', ...)`，没有类型约束，payload 结构也没有在 shared 层定义。

### 缺失环节四：事件 payload 结构缺乏前后端契约

工具内部构建的 enrichedPayload 包含 `_event`、`_sessionId`、`_agentName`、`_timestamp` 等内部字段，加上用户传入的 payload。但前端需要消费的字段没有规范定义（例如 `open-preview` 的 `url`、`title`，`notify` 的 `message`、`level`）。

## 影响范围

- **功能完全不可用**：所有三种预定义事件都无法推送到前端 UI
- **Agent 行为异常**：Agent 调用 `emit_event` 后收到 success 返回，以为事件已送达，但前端毫无反应
- **调试困难**：context.jsonl 中能看到工具被调用，但无法验证前端是否收到

## 相关文件

- `src/main/agent/tools/builtin/emit-event.ts` — 工具定义（发射端）
- `src/main/agent/tools/__tests__/emit-event.test.ts` — 工具测试（验证 EventBus 发射）
- `src/main/publishers/` — Gateway EventBridge 目录（StreamPublisher、ThreadPublisher）
- `src/main/common/gateway/` — Gateway 实现（broadcastEvent、server）
- `src/shared/events/` — 事件类型体系
- `src/shared/stream-protocol.ts` — 流式消息协议
- `src/renderer/` — 前端（需要添加事件 handler）
