# P2 - 性能与稳定性优化 POC

## 概述

本 POC 旨在解决 Agent 模块中影响性能和稳定性的 3 个 P2 级别问题，提升系统的健壮性和开发体验。

## 问题列表

### P2-1: 主进程同步文件 IO 过多
- **影响**：高频场景下主线程阻塞，可能导致 UI 卡顿
- **方案**：分层异步化，优先改造事件写盘路径

### P2-2: CoreSkills 旧机制残留
- **影响**：代码与文档不一致，增加理解成本
- **方案**：直接删除或移至 legacy/

### P2-3: Skill 缓存与热重载联动缺失
- **影响**：热插拔后缓存仍生效，开发体验差
- **方案**：Hook Extension 生命周期，主动失效缓存

## 推荐方案

- **P2-1**: ⭐ 上策 - 分层异步化（事件写盘优先）
- **P2-2**: ⭐ 直接删除 CoreSkills
- **P2-3**: ⭐ Hook Extension 生命周期

## 实施顺序

1. P2-2（最低风险，快速完成）
2. P2-3（低风险，改善开发体验）
3. P2-1（中风险，需要充分测试）
