# Agent Executor 简化调用 - 需求分析

> 创建时间：2026-04-28

## 需求背景

当前 `AgentExecutor` 同时承担 Thread/Agent 装配、并发控制、Abort、环境准备、Extension 生命周期、Runtime 构建、事件转发、状态同步和清理。调用链能工作，但内部变化轴过多，后续扩展时容易让外部调用方参与复杂组装。

## 核心目标

- 对外保持最简单的调用模式：调用方只传 `threadId + message` 或标准 `AgentExecuteRequest`。
- Thread、Agent、模型、workspace 等装配细节收敛到内部服务。
- 将 busy、abort、runStatus 等运行状态管理从 `AgentExecutor` 拆出。
- 第一版优先降低职责耦合，不改变 Runtime 行为和外部 API。

## 约束条件

- 先改一版，避免大范围重写 Runtime 或事件协议。
- 保持 `agentExecutor.streamThread()`、`submitThread()`、`submit()`、`submitAndWait()`、`abort()` 兼容。
- 不要求外部调用方构建 Builder 或手动查询 Thread/Agent。

## 涉及范围

- `src/main/agent/AgentExecutor.ts`
- 新增 `src/main/agent/execution/*`
- AgentExecutor 相关测试
