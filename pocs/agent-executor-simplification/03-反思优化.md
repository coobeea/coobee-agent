# Agent Executor 简化调用 - 反思优化

> 创建时间：2026-04-28

## 边界情况

- Thread 不存在时仍抛出明确错误。
- Agent 不存在时仍抛出明确错误。
- 同一 session 并发提交仍返回 busy 或 throw。
- Abort 不存在 session 仍返回 false。

## 对现有功能影响

- 外部 API 保持不变。
- Runtime 构建、Extension hook、Stream 事件协议不在本轮改变。
- `ThreadRunStatus` 更新改为状态去重，减少重复写入。

## 风险

- 状态管理迁移可能影响测试对 active session 的判断。
- `AgentExecutor` 仍负责 lifecycle，后续需要继续拆 `AgentExecutionLifecycle`。

## 最终调整

第一版只做两个内部服务：

1. `ThreadExecutionFactory`
2. `SessionRunRegistry`

不改 Runtime 内部，不改前端调用方式。
