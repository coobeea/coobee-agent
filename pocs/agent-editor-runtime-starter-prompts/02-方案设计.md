# 智能体编辑页运行配置与快捷问题 - 方案设计

## 上策：抽出独立运行配置和快捷问题组件

- 将运行配置和快捷问题分别抽成可复用组件。
- 优点：长期复用性最好。
- 缺点：本次问题集中在单页交互和保存链路，拆组件成本偏高。

## 中策：局部增强编辑页并修正后端 PATCH 语义

- 在 `AgentEditorView.vue` 内收敛 metadata 构造、快捷问题归一化、输入提交逻辑。
- 在 `AgentStore.update` 中将 metadata 更新改为浅合并，符合 PATCH 的局部更新语义。
- 优点：改动范围小，能直接修复保存覆盖风险。
- 缺点：运行配置 UI 仍位于当前页面内部。

## 下策：只调整前端保存 payload

- 前端每次保存都发送完整 metadata。
- 优点：最快。
- 缺点：无法保护其他调用方的局部 metadata PATCH。

## 选定方案

采用中策。它能同时解决当前页面体验和后端保存语义问题，改动范围可控，也补上可验证的回归测试。
