# 智能体编辑页运行配置与快捷问题 - 需求分析

> 创建时间：2026-04-30

## 需求背景

智能体编辑页的“默认运行配置”选中状态不够清晰，用户难以一眼判断当前默认 Runtime。快捷问题存在只能添加或保存一个的体验问题，怀疑与保存链路有关。

## 核心目标

- 优化默认运行配置的选中态和当前值展示。
- 修复快捷问题多条添加与保存稳定性。
- 避免快捷问题局部保存覆盖开场白、数据目录等其他 metadata。

## 约束条件

- 保持 Vue 3 `<script setup>` 和 Tailwind 语义色写法。
- 不重构智能体编辑页整体步骤结构。
- 后端 PATCH 应继续兼容已有调用方。

- `src/renderer/src/views/AgentEditorView.vue`
- `src/main/agent/agents/AgentStore.ts`
- `src/main/agent/agents/__tests__/AgentStore.async-list.test.ts`
