# 智能体编辑页运行配置与快捷问题 - 反思优化

## 边界情况

- 旧数据中 `starterPrompts` 不是数组时应兜底为空数组。
- 快捷问题包含空字符串或重复项时应过滤或提示。
- 用户使用中文输入法时，回车确认候选词不应误触发添加。
- 用户输入了快捷问题但未点击添加，最终保存时也应提交。
- 自动保存正在进行时，整页保存应等待它结束，避免旧快照晚到覆盖新数组。

## 安全与兼容

- metadata 改为浅合并后，空数组仍可正常清空快捷问题。
- 该策略更符合 PATCH 部分更新语义，但不支持通过 `{}` 删除整个 metadata；当前业务没有该需求。

## 可维护性

- 前端通过 `buildAgentMetadata` 统一构造保存数据，减少多处手写字段造成的不一致。
- 后端增加 metadata 合并测试，覆盖局部保存不丢字段的关键路径。
