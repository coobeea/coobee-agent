# ASR 模型路径优化 - 反思优化

## 边界情况检查

- `model_name` 是远程模型 ID：继续支持 `FunAudioLLM/Fun-ASR-Nano-2512`。
- `model_name` 是绝对本地路径：优先检查并使用该路径。
- `model_name` 是相对本地路径：相对运行时配置文件所在目录解析。
- ModelScope 缓存目录存在但权重未下载完成：不作为本地模型使用。
- 阿里云模型 `aliyun/...`：保持原逻辑，不进入本地模型加载。

## 安全隐患评估

- 不删除或移动任何本地模型文件。
- 只读取目录结构和文件名，不读取模型内容。
- 路径展开限制在用户配置和 Worker 注入的目录内。

## 对现有功能的影响

- 本地 ASR：启动时更容易命中已有 ModelScope 缓存。
- ASR 健康检查：增加解析后的本地路径字段，便于调试。
- TTS 和其他 Worker：不受影响。

## 性能和可维护性

- 启动时会递归检查候选模型目录内是否有权重文件；候选目录很少，开销可接受。
- 辅助函数集中在 ASR Worker 配置区附近，后续如需抽到共享工具也比较直接。

## 最终调整

采用“候选路径 + 完整性检查 + 健康信息暴露”的方式实现，不修改现有配置格式。
