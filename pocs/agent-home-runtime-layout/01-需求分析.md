# Agent Home 运行目录重定义 - 需求分析

> 创建时间：2026-04-30

## 需求背景

当前 Agent 运行相关文件分散在多个目录：

- `.home/agents/{agentId}`：Agent 人格、记忆、技能包等长期配置。
- `.home/workspaces/{threadId}`：会话历史、事件、上下文等运行产物。
- `.home/data/{agentId}`：Agent 级业务数据目录。

这导致几个问题：

- 一个 Agent 的长期资产不够集中，备份、迁移、排查时需要跨目录拼装。
- `workspace`、`dataDirectory`、`sessionDir` 的语义混在一起，工具 cwd 和业务数据落点不直观。
- Skill 脚本位于 Agent Home 下，但脚本执行产物希望稳定落到 Agent 的业务工作区。
- 旧路径 `.home/workspaces/{threadId}` 和 `.home/data/{agentId}` 继续存在，会让新会话和旧会话路径策略不一致。
- 后续不希望在运行期继续维护旧路径兼容逻辑，避免主流程长期背负两套目录模型。

## 核心目标

重新定义 Agent Home 内部目录边界，让每个 Agent 自包含：

```text
.home/agents/{agentId}/
  IDENTITY.md
  SOUL.md
  USER.md
  memory/
  skills/
  sessions/
    {threadId}/
      history.jsonl
      events.jsonl
      context.jsonl
      sessions/
  workspace/
```

目标语义：

- `agent_home`：`.home/agents/{agentId}`，存放 Agent 身份、人格、记忆、技能、配置。
- `data_directory`：`.home/agents/{agentId}/workspace`，存放业务数据、脚本输出、报告、索引和中间产物。
- `tool cwd`：默认使用 `.home/agents/{agentId}/workspace`，避免工具把文件写到 Agent Home 根目录。
- `session_dir`：`.home/agents/{agentId}/sessions/{threadId}`，存放会话运行产物。
- `skills`：`.home/agents/{agentId}/skills`，仍作为 Agent 私有 Skill 搜索路径。

第一阶段不新增专门的 `skill_exec` 工具。现有 `exec` 工具在新的 cwd 下执行即可；如需运行技能脚本，可以用脚本绝对路径或从 runtime paths 中定位脚本路径。

## 约束条件

- 先创建 POC，审核通过后再改代码。
- 不做旧路径的运行期兼容读取：新目录模型是唯一模型。
- 旧数据如需保留，只允许做一次性迁移；迁移完成后主流程不再 fallback 到旧目录。
- 新路径不能再回落到 `.coobee-test` 或不可解释的兜底目录。
- 旧 `metadata.dataDirectory` 自定义语义不再作为默认运行模型的一部分；如后续需要自定义工作区，应另行设计。
- 工具执行 cwd 不能设为 Agent Home 根目录，避免误写人格文件、技能包或系统索引。
- 会话运行产物和业务工作区要分开，不能把 `history.jsonl/events.jsonl/context.jsonl` 写进业务 workspace。

## 涉及范围

主要后端模块：

- `src/main/agent/context/AgentContextResolver.ts`
- `src/main/agent/AgentEnv.ts`
- `src/main/agent/AgentEnvInjector.ts`
- `src/main/agent/threads/ThreadStore.ts`
- `src/main/agent/streaming/consumers/EventWriter.ts`
- `src/main/agent/streaming/consumers/HistoryWriter.ts`
- `src/main/routes/ThreadRoutes.ts`
- `src/main/routes/FileRoutes.ts`（如仍依赖全局 workspaces 目录，需要评估）
- `src/main/agent/runtime/pimono/PiMonoSessionPaths.ts`
- 相关测试与文档

可能涉及配置/共享类型：

- `src/shared/events/thread.ts`
- `src/main/agent/threads/types.ts`
- `src/main/config/threads.ts`
- `src/main/common/env.ts`

本 POC 暂不实现：

- 新增 `skill_exec` 工具。
- UI 大改版。
- Skill 包内部目录结构重排。
- 长期兼容旧 `.home/workspaces/{threadId}` 或 `.home/data/{agentId}`。
- 自动删除所有旧会话文件；旧数据是否一次性迁移或清理，在实施前单独确认。
