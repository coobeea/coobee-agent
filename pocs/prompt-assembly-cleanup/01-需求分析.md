# Prompt 组合结构整理 - 需求分析

> 创建时间：2026-04-23

## 需求背景

`docs/04-references/ollama-last-prompt.txt` 展示的最终提示词由基础 instructions、运行时环境、AGENTS.md、Agent Home、Skill discovery 等多段内容拼接而成。当前结构可读性较弱，并且会读取全局 `.home/agents.md` 注入到所有 Agent。

## 核心目标

- 不再读取和注入全局 `.home/agents.md`。
- 将 Agent 级 `AGENTS.md` 作为明确的 Agent rules 块注入。
- 精简系统生成的 runtime environment，减少重复的路径说明和强调文本。
- 不做用户自定义内容的重复检测，避免误判 `instructions`、`SOUL.md`、`AGENTS.md` 的语义。

## 约束条件

- 保留现有 Agent 自定义能力，不自动改写用户文件内容。
- 不改变 Runtime 的执行接口，只调整 prompt append blocks 的生成方式。
- 保持 PiMono / OpenAI 通过 `appendInstructions` 接收附加块的机制不变。

## 涉及范围

- 模块：`src/main/agent/prompt/`
- 模块：`src/main/agent/AgentEnv.ts`
- 模块：`src/main/agent/agents/AgentHomeManager.ts`
- 模块：`src/main/agent/AgentEnvInjector.ts`
- 测试：`src/main/agent/prompt/__tests__/PromptAssemblyService.test.ts`
