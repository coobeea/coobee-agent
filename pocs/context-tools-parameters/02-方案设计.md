# context.jsonl 工具参数 Schema 缺失 - 方案设计

> 创建时间：2026-04-28

## 方案概述

将工具参数 Zod Schema 转换为 JSON Schema 后写入 context.jsonl，确保审计快照包含完整的工具参数定义。

## 修改点

### 1. `AbstractAgentRuntime.writeSnapshot()`

**当前代码**（line 170-172）：

```typescript
tools: options.tools.map((t) => ({ name: t.name, description: t.description }));
```

**修改方案**：使用 `z.toJSONSchema()` 将 Zod Schema 转为 JSON Schema 记录。

```typescript
tools: options.tools.map((t) => ({
  name: t.name,
  description: t.description,
  parameters: z.toJSONSchema(t.parameters)
}));
```

需要引入：`import { z } from 'zod/v4'` 或 `import { toJSONSchema } from 'zod/v4'`

注意事项：

- `z.toJSONSchema()` 输出包含 `$schema: "http://json-schema.org/draft/2020-12/schema#..."`，如果需要精简可以移除该字段
- 与 `PiMonoToolConverter.stripSchemaRef()` 保持一致的处理方式

### 2. `PiMonoAgentRuntime.buildRequestPreview()`

**当前代码**（line 513-520）：

```typescript
// 注：parameters 是 Zod Schema，这里简化存储为工具名称列表
const tools = options.tools?.map((t) => ({
  type: 'function',
  function: {
    name: t.name,
    description: t.description
  }
}));
```

**修改方案**：添加 `parameters` 字段，与 PiMonoToolConverter 相同的转换逻辑。

```typescript
const tools = options.tools?.map((t) => ({
  type: 'function',
  function: {
    name: t.name,
    description: t.description,
    parameters: stripSchemaRef(z.toJSONSchema(t.parameters))
  }
}));
```

已有的 `stripSchemaRef` 工具函数在 `PiMonoToolConverter.ts` 中：

```typescript
function stripSchemaRef(schema: Record<string, unknown>): Record<string, unknown> {
  const { $schema, ...rest } = schema;
  return rest;
}
```

需要将 `stripSchemaRef` 提取为共享函数，或在此文件中引入。

### 3. ClaudeAgentRuntime 同步检查

`ClaudeAgentRuntime.ts` 中也有 `buildRequestPreview()` 方法（line 786-855），需要同步检查是否有同样的问题。

## 不涉及范围

- **实际 LLM API 调用**：已有完整参数，不需要修改
- **PipeMonoToolConverter**：转换逻辑正确，不需要修改
- **OpenAIAgentRuntime.convertTools()**：转换逻辑正确，不需要修改

## 风险评估

- 低风险：仅修改 context.jsonl 写入逻辑，不影响执行流程
- `z.toJSONSchema()` 在运行时已可用（PiMonoToolConverter 已在用）
- JSON Schema 增加了 JSONL 文件体积，但工具参数 schema 通常较小（几个 KB）
