# 会话删除 - 需求分析

> 创建时间：2026-04-29

## 需求背景

侧边栏已经能展示最近会话，但缺少删除入口。会话创建多了以后，用户无法清理不再需要的记录。

## 核心目标

- 在会话列表提供删除能力。
- 删除后会话列表立即更新。
- 如果删除的是当前打开的会话，界面回到主页，避免停留在不存在的路由。
- 后端通过统一 API 暴露删除能力，并广播 `thread:message` 删除事件。

## 约束条件

- 正在运行中的会话不能删除，避免执行器仍在写入状态或历史。
- 第一版只删除 Thread 元数据记录，不清理工作区目录和用户生成文件。
- 删除操作需要二次确认，避免误触。
