# Worker 自启动配置展示 - 方案设计

> 创建时间：2026-04-29

## 方案

沿用现有 `worker.json` 配置源：

- `WorkerInfo` 增加 `autoStart` 字段，由 WorkerManager 从当前注册配置返回。
- 新增 `worker.autoStartUpdate` Gateway RPC，直接修改对应 Worker 的 `worker.json`。
- 修改后调用 WorkerManager 的配置重载逻辑，复用现有 autoStart 变更处理。
- 设置页使用开关展示和更新 `autoStart`。
- 详情弹窗运行状态改成一行摘要 chips。

## 取舍

不把 `autoStart` 写入 `{runtimeHome}/workers/{name}/config.json`，避免和用户明确的 `worker.json` 配置源产生双写和优先级歧义。
