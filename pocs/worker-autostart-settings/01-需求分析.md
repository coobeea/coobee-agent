# Worker 自启动配置展示 - 需求分析

> 创建时间：2026-04-29

## 需求背景

Worker 的 `worker.json` 中已有 `autoStart` 字段，应用 READY 阶段也会读取该字段决定是否自动启动 Worker。但设置页没有展示和编辑入口，导致用户无法从 UI 判断或修改 Worker 是否随应用启动。

同时，Worker 详情弹窗里的“运行状态”区域用大网格展示少量运行指标，占据空间过大，信息密度不合理。

## 核心目标

- 在 Worker 列表和详情弹窗中展示 `autoStart` 状态。
- 支持从设置页直接切换 `worker.json` 中的 `autoStart`。
- 压缩详情弹窗中的“运行状态”区域，改成紧凑摘要。

## 约束条件

- 以 `worker.json` 作为 Worker 自启动配置源，不引入新的 runtime config 来源。
- 保留现有 WorkerManager 配置热重载能力。
- 不改变 Worker 的启动/停止按钮语义。

## 涉及范围

- `src/shared/events/worker.ts`
- `src/main/common/worker/WorkerManager.ts`
- `src/main/rpc/WorkerMethods.ts`
- `src/renderer/src/views/settings/WorkersSettings.vue`
