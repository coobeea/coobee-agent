# Worker 自启动配置展示 - 反思优化

> 创建时间：2026-04-29

## 边界检查

- `autoStart` 缺省时按 `false` 展示，避免旧事件或旧配置导致 UI 空值。
- 修改 `worker.json` 后同步更新 `ManagedWorker.config`，否则状态事件可能仍返回旧值。
- RPC 只允许更新 `autoStart` 布尔值，不开放任意 worker.json 写入。

## 影响评估

修改 `autoStart` 会走现有 WorkerManager 热重载逻辑；当前逻辑在开启 autoStart 时会尝试启动 Worker，关闭时会停止正在运行的 Worker。这保持了项目已有行为。
