### 2.1 AgentContextResolver

#### 边界情况

| 场景 | 当前行为 | 新实现应对 |
|------|---------|-----------|
| Agent 不存在 | 各模块各自处理 | `resolver.resolve()` 统一抛异常 |
| workspace 为空 | 有些模块用默认值，有些报错 | 统一使用默认值或抛异常 |
| dataDirectory 未初始化 | ThreadStore 会自动创建 | Resolver 只负责解析，不负责创建 |
| 并发调用 resolve() | 无并发保护 | 如果涉及文件系统，需要加锁 |

#### 设计调整

```typescript
class AgentContextResolver {
  private cache = new Map<string, AgentContext>();
  
  async resolve(params: ResolveParams): Promise<AgentContext> {
    // 1. 参数验证
    if (!params.agentId) {
      throw new Error('[ContextResolver] agentId is required');
    }
    
    // 2. 缓存检查（避免重复查询）
    const cacheKey = `${params.agentId}-${params.sessionId}`;
    if (this.cache.has(cacheKey)) {
      return this.cache.get(cacheKey)!;
    }
    
    // 3. 加载 Agent 定义
    const agent = await AgentStore.getInstance().get(params.agentId);
    if (!agent) {
      throw new Error(`[ContextResolver] Agent not found: ${params.agentId}`);
    }
    
    // 4. 解析路径（使用现有 AgentHomeManager 和 Env）
    const agentHomePath = await AgentHomeManager.getPath(params.agentId);
    const dataDirectory = agent.dataDirectory || await Env.getDefaultDataDir(params.agentId);
    
    // 5. 构建上下文
    const context: AgentContext = {
      agentId: params.agentId,
      agentHomePath,
      dataDirectory,
      workspacePath: params.workspace,
      effectiveModel: params.modelOverride || agent.model,
      sessionDir: path.join(dataDirectory, 'sessions', params.sessionId)
    };
    
    // 6. 缓存结果
    this.cache.set(cacheKey, context);
    
    return context;
  }
  
  // 清理缓存（测试时使用）
  clearCache() {
    this.cache.clear();
  }
}
```

### 2.2 ThreadExecutionFactory

#### 边界情况

| 场景 | 当前行为 | 新实现应对 |
|------|---------|-----------|
| Thread 不存在 | ChatRoutes 报错，ThreadWaker 日志但不报错 | 统一抛异常 |
| Agent 不存在 | 同上 | 统一抛异常 |
| modelOverride 为空字符串 | 被当作有效值 | 统一处理为 undefined |
| instructions 为空字符串 | 被传给 Builder | 统一处理：空字符串不传 |

#### 设计调整

```typescript
class ThreadExecutionFactory {
  constructor(
    private agentExecutor: AgentExecutor,
    private contextResolver: AgentContextResolver
  ) {}
  
  async createBuilder(params: {
    threadId: string;
    sessionMode?: 'file' | 'memory';
  }): Promise<PiMonoBuilder> {
    // 1. 加载 Thread 和 Agent
    const thread = await ThreadStore.getInstance().get(params.threadId);
    if (!thread) {
      throw new Error(`[ExecutionFactory] Thread not found: ${params.threadId}`);
    }
    
    const agent = await AgentStore.getInstance().get(thread.agentId);
    if (!agent) {
      throw new Error(`[ExecutionFactory] Agent not found: ${thread.agentId}`);
    }
    
    // 2. 解析上下文
    const context = await this.contextResolver.resolve({
      agentId: thread.agentId,
      sessionId: params.threadId,
      threadId: params.threadId,
      workspace: thread.workspacePath,
      modelOverride: thread.overrideModel
    });
    
    // 3. 配置 Builder
    const builder = this.agentExecutor
      .piMono()
      .sessionMode(params.sessionMode || 'file')
      .name(agent.id);
    
    // 4. 应用模型配置
    const modelSpec = context.effectiveModel;
    if (modelSpec) {
      this.agentExecutor.applyProviderConfig(builder, {
        modelOverride: modelSpec,
        sessionId: params.threadId,
        agentId: agent.id
      });
    }
    
    // 5. 应用 instructions（空字符串不传）
    if (agent.instructions && agent.instructions.trim()) {
      builder.instructions(agent.instructions);
    }
    
    return builder;
  }
}
```

### 2.3 PromptAssemblyService

#### 边界情况

| 场景 | 当前行为 | 新实现应对 |
|------|---------|-----------|
| Skill 文件不存在 | SkillManager 返回空数组 | 正常处理，不报错 |
| Agent Home 超大 | 全部注入 | 增加大小限制（10000 字符） |
| AGENTS.md 超大 | 全部注入 | 增加警告，建议截断 |
| 技能信息重复 | PiMono 双重注入 | 统一只注入一次 |
| token 统计不准 | 无统计 | 使用简单估算（1 token ≈ 4 chars） |

#### 设计调整

```typescript
class PromptAssemblyService {
  private readonly MAX_AGENT_HOME_CHARS = 10000;
  private readonly MAX_AGENTS_MD_CHARS = 50000;
  
  async assemble(context: AgentContext): Promise<PromptAssembly> {
    const blocks: PromptBlock[] = [];
    const warnings: string[] = [];
    
    // 1. 基础 instructions（优先级最高）
    const agent = await AgentStore.getInstance().get(context.agentId);
    if (agent?.instructions) {
      blocks.push({
        source: 'instructions',
        content: agent.instructions,
        tokens: this.estimateTokens(agent.instructions)
      });
    }
    
    // 2. Agent Home（限制大小）
    const agentHomeContent = await this.loadAgentHome(context.agentHomePath);
    if (agentHomeContent) {
      if (agentHomeContent.length > this.MAX_AGENT_HOME_CHARS) {
        warnings.push(`Agent Home 内容过大（${agentHomeContent.length} 字符），已截断`);
        const truncated = agentHomeContent.slice(0, this.MAX_AGENT_HOME_CHARS);
        blocks.push({
          source: 'agent_home',
          content: truncated,
          tokens: this.estimateTokens(truncated)
        });
      } else {
        blocks.push({
          source: 'agent_home',
          content: agentHomeContent,
          tokens: this.estimateTokens(agentHomeContent)
        });
      }
    }
    
    // 3. Skills（只注入一次，避免 PiMono 双重注入）
    const skills = await SkillManager.getInstance().getSkills([
      context.agentHomePath,
      // ... 其他 skill 目录
    ]);
    
    if (skills.length > 0) {
      const skillSummary = this.buildSkillSummary(skills);
      blocks.push({
        source: 'skills',
        content: skillSummary,
        tokens: this.estimateTokens(skillSummary)
      });
    }
    
    // 4. AGENTS.md（检查大小）
    const agentsMd = await this.loadAgentsMd();
    if (agentsMd) {
      if (agentsMd.length > this.MAX_AGENTS_MD_CHARS) {
        warnings.push(`AGENTS.md 过大（${agentsMd.length} 字符），建议截断`);
      }
      blocks.push({
        source: 'system_agents_md',
        content: agentsMd,
        tokens: this.estimateTokens(agentsMd)
      });
    }
    
    // 5. 汇总
    const totalTokens = blocks.reduce((sum, b) => sum + b.tokens, 0);
    
    return { blocks, totalTokens, warnings };
  }
  
  private estimateTokens(text: string): number {
    // 简单估算：1 token ≈ 4 chars（英文）或 1.5 chars（中文）
    // 这里用保守估算：1 token = 3 chars
    return Math.ceil(text.length / 3);
  }
  
  private buildSkillSummary(skills: Skill[]): string {
    // 只返回摘要，不返回完整内容
    return skills.map(s => `- ${s.name}: ${s.description}`).join('\n');
  }
}
```

### 2.4 AgentEventWriter 清理

#### 边界情况

| 场景 | 当前行为 | 新实现应对 |
|------|---------|-----------|
| Extension 调用 AgentEventWriter | 正常工作 | 改为调用 EventBus 适配方法 |

```typescript
/**
 * @deprecated
 * AgentEventWriter 已不是主事件链路，现在是 EventBus 的适配层。
 * 主链路：Runtime -> Executor -> StreamEmitter -> EventBus -> Consumers

export class AgentEventWriter {
  constructor(private eventBus: EventBus) {}
  
  async writeEvent(sessionId: string, event: AgentEvent): Promise<void> {
    // 转发到 EventBus
    this.eventBus.emit('agent:event', { sessionId, event });
```

### 3.3 错误处理

**统一错误处理原则**：

1. **参数验证失败** → 立即抛异常，带清晰错误信息
2. **外部依赖失败**（如文件不存在）→ 返回默认值 + 日志警告
3. **致命错误**（如 Agent 不存在）→ 抛异常，阻止执行

```typescript
// 示例：AgentContextResolver
async resolve(params: ResolveParams): Promise<AgentContext> {
  try {
    // 1. 参数验证（立即抛异常）
    if (!params.agentId) {
      throw new Error('[ContextResolver] agentId is required');
    }
    
    // 2. 加载 Agent（致命错误）
    const agent = await AgentStore.getInstance().get(params.agentId);
    if (!agent) {
      throw new Error(`[ContextResolver] Agent not found: ${params.agentId}`);
    }
    
    // 3. 加载 Agent Home（非致命）
    let agentHomePath: string;
    try {
      agentHomePath = await AgentHomeManager.getPath(params.agentId);
    } catch (err) {
      log.warn(`[ContextResolver] Failed to load Agent Home: ${err.message}`);
      agentHomePath = ''; // 使用默认值
    }
    
    // ...
  } catch (err) {
    log.error('[ContextResolver] Failed to resolve context:', err);
    throw err; // 重新抛出，让上层处理
  }
}
```

## 八、最终调整

### 调整 1：AgentContextResolver 增加缓存

**原因**：减少重复查询，提升性能

**实现**：
```typescript
class AgentContextResolver {
  private cache = new Map<string, { context: AgentContext, timestamp: number }>();
  private readonly CACHE_TTL = 5 * 60 * 1000; // 5 分钟
  
  async resolve(params: ResolveParams): Promise<AgentContext> {
    const cacheKey = `${params.agentId}-${params.sessionId}`;
    const cached = this.cache.get(cacheKey);
    
    if (cached && Date.now() - cached.timestamp < this.CACHE_TTL) {
      return cached.context;
    }
    
    // ... 正常解析逻辑
    
    this.cache.set(cacheKey, { context, timestamp: Date.now() });
    return context;
  }
}
```
