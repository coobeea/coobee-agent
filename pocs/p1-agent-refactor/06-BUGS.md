```markdown
### 问题 #N：[简短描述]

**问题描述**：
[详细描述问题现象]

**复现步骤**：
1. 步骤 1
2. 步骤 2
3. ...

**错误信息**：
```

```

**影响范围**：
- [ ] 阻塞当前任务
- [ ] 影响其他任务
- [ ] 不影响进度

**根本原因**：
[分析问题的根本原因]

**解决方案**：
[描述解决方案]

**状态**：
- [ ] 待处理
- [ ] 处理中
- [ ] 已解决
- [ ] 已回避

**解决时间**：YYYY-MM-DD HH:MM

**相关任务**：任务 X.Y
```
