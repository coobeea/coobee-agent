# ASR 语音对话输入区 - 需求分析

> 创建时间：2026-04-29

## 需求背景

当前 Thread 对话输入区始终以普通文本输入框为主，ASR 只是运行配置里的一个开关。用户希望开启 ASR 后，输入区本身切换成语音对话模式。

## 核心目标

- 当 Thread/Agent 的 ASR 开启时，底部对话框区域切换为语音对话输入区。
- 语音模式下不显示普通文本输入框。
- 语音输入区应作为通用组件沉淀，可复用于其他对话场景。
- 保留运行配置、模型选择、上下文用量等输入区工具入口，确保用户能在同一区域关闭 ASR。

## 约束条件

- 改动范围只限前端对话输入区域，不调整 ThreadView 整体布局。
- 遵循 Vue 3 `<script setup lang="ts">`、TypeScript 和现有语义颜色体系。
- 不破坏已有文本输入模式和文件引用插入能力。

## 涉及范围

- `src/renderer/src/components/chat/ChatComposer.vue`
- `src/renderer/src/components/chat/VoiceConversationInput.vue`
- `src/renderer/src/stores/worker.ts` 的现有能力仅复用，不新增 Store API。
